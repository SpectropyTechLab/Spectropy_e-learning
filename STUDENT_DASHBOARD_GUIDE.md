# Student Dashboard Guide

This document explains how a student can:

1. Log in to the LMS
2. View enrolled courses on the dashboard
3. Open a course
4. Navigate chapters and topics
5. Use the course content viewer
6. Track learning progress

## 1. Student Dashboard Overview

After logging in as a student, the user is taken to the `Student Dashboard`.

The dashboard contains:

- A left sidebar
- A main content area
- A list of enrolled courses

The student dashboard is the main page where students can access their assigned learning content.

## 2. Left Sidebar in Student Dashboard

The left sidebar contains:

- Platform logo
- `Student Dashboard` title
- `Courses` button
- Student profile display
- `Logout` button

### `Courses` button

This button opens the student’s course list.

Note:

- In the current dashboard, `Courses` is the main active section

### Student profile section

This section shows:

- Student name
- Student email

### `Logout` button

This button logs the student out of the system and returns the user to the login page.

## 3. Main Content Area

The main content area displays:

- `Active Courses` heading
- A short dashboard description
- Course cards for enrolled courses

If courses are loading, a loading placeholder is shown.

If no courses are available, the student sees:

- `You are not enrolled in any courses yet.`

## 4. Which Courses Are Visible to the Student

A student will only see courses when:

1. The student is enrolled in the course as `student`
2. The course is published by the admin

If the student is enrolled but the course is still in draft, the course will not appear on the dashboard.

## 5. Course Cards on Student Dashboard

Each course card shows:

- Course title
- Course description
- `View Course` button

### `View Course` button

This button opens the full course learning page for the selected course.

## 6. Step-by-Step: How Student Uses the Dashboard

### Step 1: Log in

1. Open the LMS login page
2. Enter student login credentials
3. Click `Login`

### Step 2: Open the Student Dashboard

1. After login, the system opens the `Student Dashboard`
2. The `Courses` section is shown by default

### Step 3: View available courses

1. In the main area, check the `Active Courses` section
2. Review the list of displayed course cards

### Step 4: Open a course

1. Find the required course card
2. Click `View Course`

Result:

- The selected course page opens

## 7. Student Course Page Overview

After clicking `View Course`, the student is taken to the course page.

This page has two sections:

### Left panel

The left panel contains:

- `Course View` heading
- Progress bar
- Chapter list
- Topics/items inside chapters
- `Back to My Courses` button

### Right panel

The right panel contains:

- Course title
- Current chapter and topic title
- `Previous` button
- `Next` button
- Content display area

## 8. How Student Opens Course Content

Steps:

1. In the left panel, click a chapter name to expand it
2. The topics under that chapter become visible
3. Click the required topic
4. The content opens on the right side

## 9. Chapter Expansion on Student Course Page

Each chapter can be expanded or collapsed.

When a student clicks the chapter name:

- If the chapter is closed, it expands
- If the chapter is open, it collapses

This helps the student browse course structure easily.

## 10. Topic/Item List in the Course

Inside each chapter, students can see content items such as:

- Video
- Audio
- PDF
- SCORM package
- HTML lesson
- Text lesson
- External link

Students can click any item title to open it.

## 11. Previous and Next Buttons

At the top-right side of the course page, the student can use:

- `Previous`
- `Next`

### `Previous`

Use this button to move to the previous topic in the course sequence.

### `Next`

Use this button to move to the next topic in the course sequence.

Important:

- When the student clicks `Next`, the current item is marked as completed

## 12. Progress Tracking

The student course page contains a progress bar.

The progress bar is based on:

- Total number of course items
- Number of completed items

### Completion mark

When an item is completed:

- A check mark appears beside the item in the chapter list
- The progress bar updates

## 13. Content Types Students Can View

The student content viewer supports these content types:

### Video

- Opens in a video player

### Audio

- Opens in an audio player

### PDF

- Opens in a PDF viewer

### SCORM

- Opens in the SCORM player

### HTML

- Opens as lesson content

### Text

- Opens as text lesson content

### External Link

- Opens the linked content through the content viewer

## 14. Back to Course List

Students can return to the course list at any time.

Steps:

1. On the course page, click `Back to My Courses`
2. The system returns to the dashboard course list

## 15. Step-by-Step Full Student Example

1. Student logs in to the LMS
2. Student reaches the `Student Dashboard`
3. Student opens the `Courses` section
4. Student sees the list under `Active Courses`
5. Student clicks `View Course`
6. Student expands a chapter
7. Student clicks a topic
8. The content opens on the right side
9. Student studies the content
10. Student clicks `Next`
11. The system marks the current item as completed
12. The progress bar updates
13. Student continues until all content is completed

## 16. Common Reasons a Student Cannot See a Course

If a student does not see a course on the dashboard, check the following:

- The student is not enrolled in that course
- The student was enrolled with the wrong role
- The course is still in draft and not published

## 17. Quick Checklist for Students

Before starting learning, confirm:

- You are logged in with the correct student account
- Your course appears in `Active Courses`
- You can click `View Course`
- The chapter list is visible
- The content opens correctly

## 18. Summary

The student dashboard helps the learner:

- View enrolled and published courses
- Open course content easily
- Navigate chapter by chapter
- Track progress with completion status
- Return to the dashboard whenever needed
